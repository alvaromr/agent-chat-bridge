# User-facing text is in Spanish
- **Practice:** every artifact in English, except copy for users.
- **Value not at stake:** none: this is the exception for users' copy, applied to its reader.
- **Why:** the user reads the CLI help and errors, toasts, the settings modal, prompts and the skill's replies in
  Spanish. Logs, internal errors and test names are in English.
- **Decided by:** the owner, 2026-10-29.
